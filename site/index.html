Each answer is scored 0–10 by a reference-grounded blind judge handed the gold answer, so the scores are checkable. It all tests one claim: fine-tuning teaches the answer's shape; retrieval supplies the facts.

How the judge works

An open-book judge, blind to the system

Every answer is scored by a Gemini judge (gemini-3.1-flash-lite) that never sees which system produced it, and scores one answer at a time so nothing is flattered by comparison. Each held-out question is handed to the judge with its source evidence and a gold answer, so the score is checkable against a known-good reference rather than a popularity contest.

The rubric

Four dimensions add up to 10, so a nearly-right answer separates cleanly from a hopeless one:

DimensionPointsWhat it measures
Correctness0–5Factual agreement with the gold answer
Completeness0–2Covers the key points, not just one
Groundedness0–2No invented cards, figures or citations — fabrication forces this to 0
Clarity0–1Answers what was asked, without padding

What keeps it honest

  • Reference-grounded — the judge grades against the gold answer + evidence, not vibes.
  • Blind & pointwise — it is never told which system wrote the answer, and scores one at a time.
  • Groundedness is scored separately from correctness — an answer can be honest but incomplete, or fluent and fabricated.
  • A refusal beats a confident wrong answer — bluffing is punished, not rewarded.
  • Paired testing — the same 60 questions per system, compared with a bootstrap 95% CI (primary), cross-checked by a paired t-test and Wilcoxon.
Corpus used for training

What the fine-tune was built from

The fine-tune's supervised set is 2,683 grounded QA pairs, distilled by a teacher LLM from a curated Yu-Gi-Oh corpus and filtered through a blind-judge gauntlet. That corpus is two free sources: Yugipedia editorial prose (CC BY-SA 4.0, attributed) and YGOPRODeck card facts. Card effect text is © Konami, used only as labelled fair-use context — never a verbatim-recall target.

Cost to build

What this cost · ≈ $3 of a $25 budget

Two bills: Modal for the GPU training, and the Gemini API for generating the QA data and running the judge. The base is Google's (free); retrieval, serving and eval ran on a local RTX 3060.
